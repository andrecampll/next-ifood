# Propuesta 🔥
Este proyecto es un estudio de la interfaz de iFood.
La idea es simular una aplicación de entrega de alimentos, obteniendo datos de una API falsa e integrando la información disponible en pantalla, como los restaurantes disponibles para el cliente. La diferencia de este proyecto es el modo responsive construido para todos los dispositivos móviles y las páginas creadas utilizando Server Side Rendering (SSR).

# ¿Cómo obtener este repositorio? 🤔
Para obtener este proyecto, sigue los siguientes pasos:
1. Clona este repositorio usando <code> git clone </code>.
2. Ejecuta el comando <code> yarn </code> en la raíz de la carpeta del proyecto clonado para descargar las dependencias.
3. Ejecuta <code> npx json-server server.json -p 3333 </code> en la raíz de la carpeta del proyecto para inicializar la API falsa. <br/>
(si lo deseas, puedes usar la URL pública de la API gestionada por My JSON Server, que viene por defecto en el archivo api.ts)
4. Ejecuta <code> yarn dev </code> en la raíz de la carpeta del proyecto para iniciar la aplicación en modo de desarrollo.
5. Abre la aplicación en tu emulador. 🚀
